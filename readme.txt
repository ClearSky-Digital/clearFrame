A clear, simple frame for a website. No page builder, no bundled plugins, no bloat.

== Description ==

ClearFrame is a small classic theme with a calm, finished default look. Colors, fonts and spacing are CSS custom properties, and the header, content and footer have named hooks, so each site can get its own look from a plugin or a child stylesheet.

* Primary and footer menus, a footer widget area, a custom logo.
* Skip link, visible focus and a mobile menu that works from the keyboard.
* System font stack, so no fonts are loaded from other servers.
* The footer shows only the site owner's copyright. A "Built on ClearFrame" credit is available in the Customizer and is off by default.

== Privacy ==

The theme collects no user data and makes no requests of its own. Avatars in comments come from Gravatar through WordPress core when avatars are turned on in Settings > Discussion.

== Frequently Asked Questions ==

= How do I change the look? =
Override the CSS custom properties listed in HOOKS.md from a child theme or a plugin.

= Does it include SEO or other plugin features? =
No. Those belong in plugins.
